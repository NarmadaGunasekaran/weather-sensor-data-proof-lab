Weather Data Compression Lab

A local Python web application that uploads weather data, compares a trained weather-aware lossless codec with standard algorithms, and proves the original file is restored exactly.

The input

Weather API or weather-station JSON, CSV, or TXT data: temperature, humidity, or wind-speed readings.

The comparison

A transparent trained weather codec is compared fairly with GZIP, zlib, BZ2, LZMA, and an adaptive predictor.

The proof

Each output is decompressed. A SHA-256 and byte-for-byte check confirm that no original data changed.

How it works

01
Upload data

The app reads the file in memory. It does not save uploaded data.

02
Measure compression

It records compressed bytes plus encoding and decoding time for every method.

03
Verify losslessness

It accepts a result only after the decoded bytes exactly match the original upload.

Why this matters: The project does not say “AI is always better.” It creates evidence. Users can see the best result for their data and confirm that every weather reading is preserved.
