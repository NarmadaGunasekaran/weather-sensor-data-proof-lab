The design question

Can an encoder that adapts to recurring patterns in time-series API data compete with established compression algorithms—while preserving the raw JSON response exactly, including key ordering and whitespace?

Approach 01 · Train once

Trained weather agent

A lightweight model learns which byte usually follows each two-byte context from seven historical daily payloads. Runtime uses that fixed learned profile to encode exact residuals.

  • Customised from representative samples
  • Portable, fingerprinted agent artifact
  • Strictly reversible residual encoding
Approach 02 · Standard

Established compressors

zlib, gzip, bz2, and lzma operate on the raw JSON byte stream. They provide dependable baselines for compression ratio, speed, and operational simplicity.

  • Battle-tested implementations
  • No data-specific model needed
  • Strong baseline for every dataset

Train once. Compress anywhere. Reconstruct exactly.

The proof of concept separates learning from runtime: the same fixed agent is used to encode and decode. Its fingerprint prevents accidental use of the wrong profile.

01 · Train

Learn a profile

Feed representative historical weather JSON into the trainer. It saves a small, portable prediction table.

02 + 03 · Runtime

Encode, then restore

Encode new data using the fixed profile. The receiver uses the matching profile and exact residuals to recreate the original bytes.

Built with Python standard library only · Input can be any raw one-day JSON API response.

Run: PYTHONPATH=src python3 -m weather_compression.benchmark weather-day.json
